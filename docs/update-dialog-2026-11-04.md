# 每日更新提示与进度面板

2026-11-04 开发实现与预览，VERSION/package.json 保持 3.3.1，未安装、打包或发布。保留此前分页修复，不改真实壁纸库、不重启生产 Codex。

沿用项目 MIT 许可的 WPF 更新、弹窗、按钮、品牌字标与 RSA 签名验证实现，来源为 scripts/update-ui.ps1、skin-manager.xaml、update-progress.ps1 与 LICENSE。无新增依赖或外部图标。局部扩展遵循 DESIGN.md 的浅蓝/白/深蓝基线，Microsoft YaHei UI / Segoe UI 字体，22/15/14/13 字号，600 宽面板、36 内边距、20 圆角和 46 高按钮。公告与进度共用容器；状态切换使用尊重系统动画设置的 140ms 淡入，不在每条进度消息上重置焦点。

行为：以 Windows 本地日历日期判断每日首次启动是否需要检查，等待初始化空闲后执行一次并停止启动计时器；成功后同日不重复，网络失败保留既有退避策略，下次打开到期可重试。手动检查绕过日期和跳过版本限制。自动发现新版和手动发现新版使用同一个居中面板；手动检查还包含检查中、最新版本与失败状态。跳过按具体版本持久化。

确认更新后直接显示下载进度，支持取消；下载与签名/哈希校验成功后自动交接现有独立安装窗口，不再要求第二次点击安装。下载显示实测百分比，校验和安装显示阶段状态；系统减少动画时停止不确定进度动画。失败显示可读原因与关闭入口。弹窗限制 Tab 导航并恢复原焦点；Escape 在空闲时关闭，在更新中不打断安装。

验证：app-update、update-ui、update-progress、update-handoff、update-hardening、update-warning-color、update-close-guard 与 gallery-pagination 测试通过（最后修改的更新界面与进度测试再次复验）。覆盖本地跨日/同日、签名/哈希、跳过、取消、安装边界替身、成功/失败、交接超时/已退出/关闭否决和分页。1440×840 与 900×525 的公告、37% 下载渲染已查看。

限制：update-flow 首次遇到临时文件 Replace 失败，重试的网络/缓存/跳过/离线部分通过，但真实安装边界部分被当前生产管理器的全局互斥锁拒绝；未关闭生产程序以绕过。update-release-notice 是需公开历史包参数的兼容性测试，本次无新发行，未提供发行参数，不计入通过。未验证新功能的真实服务器下载至生产安装，也未做物理鼠标、跨屏 DPI 和动效流畅度验收；独立安装窗口沿用既有版式。
