## 风险清单与实际修复

严重程度：P1 为重要设置丢失或交付阻断，P2 为局部功能/恢复障碍，P3 为维护与说明问题。以下每项均给出证据，未复现的风险单列。

| 编号 | 等级、触发和用户影响 | 根因与处理 | 验证 |
| --- | --- | --- | --- |
| A1 | P1 保存失败后切换壁纸/关闭，未保存清晰度会被覆盖或丢失 | `Save-DynamicManagerOpacity` 留下草稿，但选择、来源、列表重建、工作启动和关闭未统一检查。增加保存门禁；失败维持原选择与数值；关闭可返回重试或明确放弃 | `manager-draft-recovery` 用真实独占文件锁复现，修复前失败，修复后检查选择、筛选、来源、删除、预览关闭、窗口关闭、恢复保存和明确放弃 |
| A2 | P2 某项目录禁止枚举时整库加载失败 | `Read-DynamicWallpaperItem` 的可选磁盘统计在异常边界之外。统计失败归零，不阻止可读媒体；重新检查重解析点，不放宽安全约束 | `wallpaper-read-fault` 使用真实 ACL 只拒绝目录枚举；修复前抛出 AccessDenied，修复后两张壁纸均返回；测试恢复 ACL 后清理临时目录 |

## 用户旅程地图

“核查”包含源码追踪和隔离行为验证，不表示每条路径都在真实 Codex 中点击通过。各测试的实际结果以验证清单为准。

| 用户入口/情形 | 系统做什么、用户看见什么 | 失败后继续方式与覆盖边界 |
| --- | --- | --- |
| 首次下载、安装 | Release EXE → 安装目录/占用检查 → 文件和清单 → 开始菜单单入口 → 打开管理器；开发中的任务保护另外注册后台 | 目录/占用错误中止，不绕过检查；本轮脚本安装在临时目录检查回滚/快捷方式，未执行新版 EXE 生命周期 |
| 首次打开和连接 | launcher 去重，管理器先 LibraryLoad，再检测 Codex/连接；库不被重启询问遮住 | 未找到 Codex 可定位；需要重启时确认/取消；首次启动与连接 worker、库优先回归 |
| 日常打开、关闭后重开、重复点击 | launcher 互斥、已有会话复用；关闭管理器不等于结束壁纸后台 | 忙碌时关闭被拦截；新增未保存草稿保护；真实连续点击窗口未验 |
| 登录启动、已有后台、多实例 | 开发补丁按安装根和用户拥有任务，重复触发忽略；监控/worker 按身份区分 | 临时任务注册、停止后恢复、归属保护以及多实例测试；注销登录、电池切换和物理重启未实测 |
| Codex 未运行/已运行 | 发现已注册安装和进程，核实 CDP 身份，健康连接复用；缺少参数不直接强制重启 | 确认重连或延后；多实例保守处理；当前生产播放状态未重新验收 |
| Codex 更新/重启 | 监控稳定观察后请求恢复，记录对同进程的延后选择 | 仅明确确认允许重启；更新恢复、过期选择和重复后台测试。官方普通入口不能全部接管 |
| 选择、预览、应用、切换 | 分页/筛选保序；预览不改真实背景；应用确认后校验媒体，事务保存并验证，失败回滚 | 新增坏图句柄释放和草稿门禁；预览、取消、应用状态、媒体回滚及 Node 渲染器测试 |
| 暂停、恢复 | 管理器恢复原始外观；渲染器另有隐藏暂停/可见恢复；两者含义不同 | 不把预览停止、恢复原始外观和后台暂停混称；恢复失败保留信息，Node 恢复用例通过，GPU 播放未验 |
| 加载图库、空库、不可用媒体 | 缺失/损坏本地项显示不可用，其余继续；空分类/空库提示；Steam 失效引用隐藏 | ACL 故障现在不会拖垮整库；Steam 源消失与缓存用例；隐藏失效外部引用仍沿用现有策略 |
| 导入、重名/重复、删除 | 校验/转换/暂存后在库锁内提交，重复选择原项；删除当前应用项受保护；只删自有副本 | 损坏文件、取消/失败回滚、并发、中文路径测试；真实原文件/Steam 源保留 |
| 清晰度保存、旧配置迁移 | 300ms 自动保存、原子写入、库互斥；旧主题/旧品牌状态迁移 | 保存失败保持数值和选择，检查文件/权限后重试；放弃只丢本次草稿，不改变之前保存值；旧迁移回归 |
| 更新发现、下载 | 签名清单 → 版本比较 → 有界下载/取消 → hash/cache 复验 → 暂存 helper | 错误可重试，已损坏缓存不复用；旧仓库地址/安装包别名保留；真实网络中断与 CDN 情况不等同于模拟传输测试 |

| 卸载、取消/失败、保留数据 | 恢复外观成功后才删除拥有的任务、恢复未被用户修改的快捷方式，再卸载程序文件 | 取消静默停止，恢复失败保留程序/库；任务移除/快捷方式逐字节恢复和卸载函数回归。安装器端到端引用旧证据，不算本轮重验 |

补充场景：损坏缩略图删除、仅目录枚举权限不足、文件被独占、确认关闭后放弃草稿、快速连续来源切换、未安装 Codex 的离线图库、任务计划禁用时会话监控降级，以及旧公开包覆盖本机补丁。

## 保留的兼容与未改范围

- 保留旧品牌更新发现地址、两种 ZIP/安装包名称、RSA 签名协议、公钥与清单 schema，不更改数据格式。
- 保留 Dream Skin/旧菜单迁移、旧安装根识别、PID/启动时间/脚本/端口身份检查。它们不是“重复代码”即可删除的垃圾。
- 保留备份、历史候选包和 XAML 备份文件；包采用显式白名单，本轮只移除已失效白名单项，没有清理用户历史工作。
- 保留原有布局、等比例缩放、分页和延迟拖窗。小窗口会同步缩小文字，这是明确的剩余体验成本；不据此擅自恢复已撤回重设计。
- 预览/确认等部分显隐仍是直接切换；未满足“每个元素均出现/退出/形变动画”的完整要求。现有来源切换、选择和加载动画及减少动态效果已检查；全面动效需要单独状态覆盖与真实观感验收，不以新增装饰动画冲抵可靠性问题。

## 剩余风险与优先级

1. **P1 发布前**：current 与公开源码仍有此前修改（后台任务、快捷方式、运行时/签名工具等）；必须按 `runtime-vs-release.json` 逐项选入下一发行副本，重新构建、签名、完整 EXE 安装/升级/卸载和 CI 验收。本轮修复不授权发布，也未把版本升级。
2. **P2 生产连接**：无调试参数的已运行 Codex 仍需一次用户确认重启；后台任务恢复不代表实际壁纸播放恢复。生产验证须另行授权。
3. **P2 可读性/辅助技术**：保留的整窗缩放在 900×525 会缩小文字；真实键盘、屏幕阅读器、跨屏 DPI 和长中文路径的完整 UI 旅程尚未验收。离屏边界检查不能证明可访问性合格。
4. **P2 断电/满盘/网络**：原子替换、锁和故障注入降低风险，不证明掉电/磁盘耗尽安全；没有真实满盘、断电、策略禁用任务或代理网络环境验收。
5. **P2 升级本机补丁**：当前公开 3.1.1 不含本机独立后台保护，覆盖安装可能替换该补丁；保留明确说明，不自动升级本机。
6. **P3 性能**：本轮证明坏图句柄立即释放、缓存仍复用，没有 CPU/GPU/启动时间前后对照，不能声称整体性能提升。动画遍布每个元素也可能增加资源占用与操作等待，应按实际状态评估。

完整验证结果另见 [验证清单](ux-audit-2026-11-02-validation.md)。失败原日志、修复前文件、修复后日志并存；“没有发现更多问题”不构成没有缺陷的证明。
