# 3.5.0 发行执行计划

> 执行方式：使用 executing-plans 在当前会话推进，并由独立审查代理检查最终发行差异。用户已明确授权检查、测试与 GitHub 发布。

**目标：** 将已认可的日夜切换、专注预览、媒体标签与现有可靠性修复发布为 3.5.0。

**架构：** 从远端 main 建立独立发行副本，只复制已核对源码与必要测试、资源、许可证。CI 构建产物经签名、隔离安装/升级和公开下载复验后成为唯一正式包。

**技术栈：** PowerShell 5.1、WPF、固定 Node 24.22.1、Inno Setup、GitHub Actions。

**规范：** DESIGN.md、docs/focus-preview-2026-11-05.md、docs/night-mode-2026-11-05.md，以及用户本轮发布授权。

## 约束与审查重点

- 不覆盖公开 3.4.0 标签或附件；本机已安装界面更新保留独立备份，不在发行验证中反复安装生产。
- 新主题资源必须进入安装清单，旧用户默认白天；旧配置及真实壁纸库保留。
- 专注预览不改变媒体比例，返回保留分页/筛选/选择；确认层必须覆盖管理面板。
- 关闭与取消不能留下锁或媒体句柄；减少动态效果、快速主题切换、加载失败需回归。
- 进程身份不确定时不能结束进程；原生启动兜底不能把模拟激活当作真实客户端验收。
