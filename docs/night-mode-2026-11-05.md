# 日夜模式接入与验收

2026-11-05，当前开发版本 3.4.0。用户已认可并要求采用夜间方案；本次为开发源码集成，未打包、发布或安装。现有未发布桌面启动修复保留。

## 已实现

- 右上角“导入壁纸”左侧增加太阳/月亮滑块，首次默认白天，单击切换。图标、焦点、悬停、按下、禁用及辅助技术名称均有对应状态。
- 延续已认可布局和白天外观，夜间使用深蓝灰背景、分层面板、浅色文字和蓝色操作色。主界面、管理与更新、关于、确认、重命名、更新面板和右键菜单使用同一主题资源。
- 滑块、背景、文字、边框及字标同步进行约 300 ms 的缓入缓出；连续点击从当前动画值重新定向。窗口关闭清理时钟与事件，尊重 Windows 减少动态效果设置。
- 壁纸图片和预览内容保留原色。切换不重建图库，不改变选择或引擎配置。
- 外观单独保存在状态目录 `manager-appearance.json`，450 ms 防抖并在关闭时补存；重开直接恢复。保存失败保留原文件和待存状态，显示提示并在后续切换或关闭重试；损坏配置回退白天，单纯读取不覆盖原文件。

## 来源和适配成本

- 视觉与交互参考 [WPF UI](https://github.com/lepoco/wpfui)（MIT）；未复制组件代码、未引入包或迁移框架。使用项目现有 PowerShell/WPF 资源与原生动画时钟。
- 太阳、月亮采用 [Microsoft Fluent System Icons 1.1.344](https://github.com/microsoft/fluentui-system-icons/tree/1.1.344)（MIT）。固定 URL、SHA256 和文件清单见 `assets/fluent-icons/`，完整许可保留于该目录及 `THIRD_PARTY_NOTICES.md`。
- 新增 `scripts/manager-theme.ps1`、`manager-theme.cs`、`manager-theme-palette.json`，已加入构建文件清单；没有新增第三方运行依赖。
