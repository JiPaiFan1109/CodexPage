# CodexPage 3.1.0

本次修复实际使用中暴露的后台目录错误、更新被重复后台拦截，以及连接确认期间误显示空壁纸库的问题。

- 修复导入后台脚本覆盖管理器状态目录，导致后台错误指向上一级目录；启动前校验安装根
- 后台按规范化路径保持单实例，重复打开管理中心复用已有守护
- 升级前验证全部进程身份；安全退出本安装的后台及符合严格身份、时效和闲置条件的旧版错根后台
- 先加载壁纸库再尝试连接，重启确认不再遮住未加载的壁纸列表；读取失败明确显示错误
- 保留宿主更新后的连接检测和重连确认；取消不会自动反复要求重启
- 补充目录污染、真实双后台升级、取消连接、库加载顺序和故障分支回归

已有用户直接运行 `CodexPage-Setup.exe` 覆盖升级，沿用原安装目录，先退出管理中心。无需先卸载，壁纸库保留。旧版自动更新助手仍为旧代码；若报告安装未完成，可退出管理中心后运行本页安装包。

本版无法保证 Codex 自身更新期间连接永不中断。普通入口启动且没有调试端口时，仍需用户确认后重新启动 Codex 才能恢复壁纸。不能仅凭测试通过推断所有驱动、跨屏、断电和满盘场景均无缺陷。

沿用 MIT 开源引擎、Node 24.22.1、WPF 与既有库格式。FFmpeg 按需确认下载；不支持 Wallpaper Engine 完整交互场景。更新清单带 RSA 签名，附件提供 SHA256；安装器未使用项目 Authenticode 证书。
