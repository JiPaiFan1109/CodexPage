# CodexPage 3.6.0

本次更新集中改善图库浏览、后台初始化、导入诊断和可访问性，保留现有日夜与专注预览界面。

1. 减少图库读取、分页刷新、后台初始化和运行时探测中的重复工作。
2. 预览图片采用最近使用缓存，并增加像素估算预算，减少长期浏览时的缓存占用。
3. 媒体读取增加超时处理，并为导入改名或提交失败保留脱敏诊断。
4. 补充窗口按钮和图库卡片的可访问名称，保持现有日夜外观。
5. 减少壁纸切换清理时的重复图片解析，保留完整校验和失败回滚。

升级保留壁纸库和设置。缓存最多 64 项、64 MiB 像素估算预算；这不是进程内存上限，淘汰后回看会重新解码。媒体 WinRT 单步等待上限为 60 秒，慢速设备可能需要重试。

此前偶发的导入访问拒绝尚未自然复现，本版增加定位证据，不宣称已修复其根因。安装包没有项目 Authenticode 签名，应用更新清单沿用既有 RSA 签名。
