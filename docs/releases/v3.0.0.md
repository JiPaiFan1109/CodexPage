# CodexPage 3.0.0

本次集中改进媒体导入、运行恢复、更新可靠性和键盘操作，保留现有壁纸库、排序、筛选与转换确认流程。

- 更新下载与安装分开，支持取消下载、复用已验证缓存，安装前由用户确认
- 增加安装占用保护、完整文件校验、启动就绪检查和慢安装日志入口，改进检查失败重试与宿主更新后的恢复
- 修复残缺转换器缓存、离线批次重复下载及无效媒体的处理；解码器输出超限时及时停止
- 成功切换后清理本次回滚副本，避免持续占用磁盘；保留失败与历史恢复记录
- 修复视频服务启动失败时的进程残留，以及视频挂载被拒绝时的状态提交
- 连接、搜索和选择动画遵循 Windows 动画设置；确认框正确转移、限制和恢复键盘焦点
- 内置运行时更新至 Node.js 24.22.1，并继续验证官方 SHA256 与签名

下载 `CodexPage-Setup.exe` 进行安装或覆盖升级。已有壁纸库无需先删除，也不建议先卸载。旧版首次升级仍使用旧更新助手；若自动更新未完成，请退出管理中心后手动运行新版安装包。

FFmpeg 仍在需要转换且用户确认后从上游下载并校验，不内置于发行包。场景与网页仍仅支持标注的预览素材，不支持完整互动场景。

项目安装器尚无项目 Authenticode 证书；Node.js 的上游签名不代表安装器签名。更新清单另有 RSA 签名，附件提供 SHA256。请勿关闭 Windows 安全保护。
