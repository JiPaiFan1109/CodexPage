# CodexPage 3.3.0

壁纸管理操作集中到右键菜单，新增关于软件，并保留应用后壁纸不再误回跳的修复。

## 用户可见变化

- 在图库中右键一张壁纸，可预览、应用、重命名或删除。右键自动选择该壁纸，删除仍需确认，正在应用的壁纸受保护。
- 将预览区的重命名和删除移至右键菜单；图库右上角说明点击预览、右键管理和长按拖动排序。
- 右上角管理面板新增关于软件，显示项目 GitHub、作者邮箱 jipaifanyyds@gmail.com 和当前版本。
- 保留并回归验证此前“应用成功后壁纸回跳”的修复：正确保留引擎进程退出句柄，避免把成功误判为失败并恢复旧壁纸；清理备份失败也不会触发再次应用或回滚。这是既有修复的延续，不是新的故障归因。
- 延续 3.2.0 后台恢复、保存失败草稿保护和图库容错，合并最新 README、教程与版本一致性检查。

## 安装与升级

下载 `CodexPage-Setup.exe`，退出 CodexPage 后安装到原目录，无需先卸载；壁纸库与设置保留。旧客户端更新地址、安装包别名与 RSA 签名协议继续兼容。若当前 Codex 会话缺少壁纸连接，仍可能需要用户确认重连。

## 验证边界

验证记录见 [v3.3.0-validation.md](v3.3.0-validation.md)。隔离测试不改维护者生产安装，不重启生产 Codex，不操作真实壁纸库。真实 GPU、多屏、辅助技术、断电和满盘未实测。安装 EXE 尚无项目 Authenticode 签名，更新清单沿用 RSA 签名。
