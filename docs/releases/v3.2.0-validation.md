# 3.2.0 验证记录

以公开 3.1.1 为源码基线，纳入后台恢复及 2026-11-02 用户体验修复。生产安装仍独立于发行源码；本次不覆盖生产安装、不重启生产 Codex、不修改真实壁纸库。

## 已核实的检查

- 固定 Node 24.22.1：52 项 Node 回归通过；161 个 PowerShell 脚本解析无错误。
- 当前用户的隔离任务计划：终止模拟监控后恢复，重复启用不重复进程，任务所有权验证及清理通过。
- 独立中文目录下 ZIP 安装通过；候选包 77 项包清单、62 项安装清单与源码和 ZIP 字节匹配。
- 隔离 Inno 安装生命周期：中文路径、新装、签名更新、占用拒绝、已记录辅助进程清理、升级保留库、取消或失败卸载、正常卸载保留库通过。
- 隔离开始菜单：新装单一入口、旧入口迁移、重复安装、空目录清理与无关入口保留通过。
- 保存失败草稿、图库读取故障、损坏图片句柄及动画中断等风险有专门回归；前一轮界面审查记录见用户体验验证清单。

## 发布门禁与证据

公开发布脚本要求最终发行提交的 `Windows UX regression review` 工作流成功，并逐一核对十附件大小与 SHA256；旧更新安装包别名、签名格式和旧仓库发现地址保留。托管 Windows CI 包含管理器实际启动、导入预览/筛选/删除/交换集成、重命名和更新关闭保护。

每次执行的完成状态以 [GitHub Actions](https://github.com/JiPaiFan1109/CodexPage/actions) 的对应提交为准。维护者本地原始记录位于 `.local-evidence/release-3.2.0/`：`full-results.json`、`lifecycle-results.json`、`payload-verified.json`、`ci-runs.json`、`public-verified.json`；这些本地证据不随安装包分发。公开下载后的复验结果由发行完成记录补充，不把候选构建成功等同于公开发布成功。

## 限制

- 本机生命周期测试跳过可见管理器启动，真实启动由托管 Windows CI 验证；不接管用户当前桌面焦点。
- 隔离安装器不自动接管真实 Codex 快捷方式，任务与快捷方式分别使用模拟进程和临时目录测试。
- 未实测真实 GPU、多屏、辅助技术、断电或满盘，不用脚本检查替代验收。
- 安装 EXE 无项目 Authenticode 签名；更新清单使用既有 RSA 签名。Windows 可能显示未知发布者提示。
- 任务计划不可用时只能降级到会话监控；普通 Codex 无连接参数时仍需用户确认重连。无法承诺接管所有应用列表或任务栏入口。
