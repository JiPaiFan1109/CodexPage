# 3.5.0 验证记录

发行验证分为源码、CI 构建和最终签名包三个阶段；最终包结果见 GitHub Release 完成记录。

## 源码验证（2026-11-05）

- 固定 Node 24.22.1：57 项测试通过。
- Windows PowerShell 5.1：132 个回归脚本全部通过，包含日夜状态保存、快速切换、专注预览往返、弹层命中、真实媒体导入/播放/释放、启动兜底、进程身份、更新与关闭取消。
- 177 个 PowerShell 脚本解析无错误；独立只读审查未发现阻塞项，图标来源摘要与 MIT 许可已核对。
- 用户已在原生实际窗口认可专注预览；本机安装 3.4.0 已单独备份并接入界面更新，不代表该更新属于公开 3.4.0 附件。
- 初次从代理宿主打开本机管理器出现基础模块解析与并发操作错误，隔离标准 Windows PowerShell 模块搜索路径后重新启动，实际 UI 确认连接成功。未据此修改系统环境变量，也未把此结论推广为所有启动故障的原因。

## 发行门槛

从同一源码提交的成功 Windows CI 获取安装包，签名后先存为草稿。必须通过安装包清单/源码/ZIP 比对、隔离新装和卸载、开始菜单、3.4.0 覆盖升级与库保留、旧客户端签名及公开下载复验。未完成前不将草稿公开。

## 限制

未实测多屏 DPI、各 GPU 动画帧率、真实屏幕阅读器、断电和满盘。启动兜底的商店激活采用隔离替身，不代表所有现场故障已实测。安装 EXE 无项目 Authenticode 签名；更新清单沿用 RSA 签名。发行测试不会再次覆盖维护者生产安装或主动切换真实壁纸。
