# CodexPage 3.7.0

1. 视频壁纸缩略图支持静音循环播放，翻页、最小化或关闭窗口时释放播放资源。
2. 左下分类改为左侧图片、右侧视频，并同步调整筛选与滑块逻辑。
3. 首次空图库内置“默认1”“默认2”“默认3”三款视频，保留原画质及用户后续改名或删除。
4. 修复部分启动环境下 Get-FileHash 命令缺失导致壁纸应用失败的问题。

三个内置视频不重新编码，沿用无损打包，安装包和磁盘占用相应增加。已有图库与设置保留，不会自动应用或覆盖用户壁纸；系统关闭界面动画时，缩略图保持静态，仍可手动打开视频预览。

安装器尚无项目 Authenticode 签名；更新清单沿用既有 RSA 签名。
