# CodexPage 3.1.1

本次统一开始菜单入口，修复升级后仍出现旧名称的问题。界面与壁纸功能保持 3.1.0 行为。

- 开始菜单只创建一个直接显示的 **CodexPage** 入口，打开壁纸管理中心
- 安装或覆盖升级时清理早期 **Codex Dream Skin**、**Codex Dream Skin - Tray** 快捷方式
- 清理旧 CodexPage 与“Codex 换肤管理中心”文件夹内的已知产品入口；仅删除空文件夹，保留用户额外放入的文件
- 不删除旧程序目录中的壁纸、主题或备份，不修改官方 Codex 快捷方式

已有用户退出管理中心后运行 `CodexPage-Setup.exe` 覆盖升级，无需先卸载，沿用原安装路径并保留壁纸库。卸载入口可在 Windows“设置 → 应用”中找到。此清理针对当前用户开始菜单；其他 Windows 账户或用户自行重命名的快捷方式不在自动清理范围。

沿用 Node 24.22.1、WPF 和原有安装/更新身份。为兼容旧版自动更新，安装目录、内部脚本名和下载兼容别名不作强制改名。更新清单带 RSA 签名，附件提供 SHA256；安装器未使用项目 Authenticode 证书。
