# CodexPage 2.3.0

- Wallpaper Engine 不兼容视频自动转码，新增 GIF/APNG 动图及 BMP/TIFF/AVIF 图片导入
- 场景与网页支持明确标注的预览图或预览动画；不支持完整场景实时渲染和互动效果
- 转换缓存去重，源文件失效后隐藏停用，保留独立本地副本
- 改善 Codex 更新后的路径刷新与重连确认，优化重启弹窗及并发保护
- 兼容文件继续引用原文件，转码为静音 H.264，最高 1080p / 30fps

安装包不含 FFmpeg。首次需要转换视频、动图或 AVIF 时从 BtbN 上游下载并校验组件（约 80 MB 下载、192 MiB 缓存），需联网；之后复用缓存。BMP/TIFF 转换无需下载。转换耗时取决于源文件大小和电脑性能。
