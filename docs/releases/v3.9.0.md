# CodexPage 3.9.0

1. 从任务栏、开始菜单、链接或开机恢复打开 Codex，以及 Codex 自动更新后重启时，都会自动接上壁纸，不再弹出“重新启动 Codex？”提示。
2. 修复新版 Codex（26.1117）下壁纸校验失败、Codex 被关闭后以无壁纸状态重新打开的问题。
3. Codex 刚启动或页面重新加载时，壁纸出现得更快、更稳定。
4. 新增云端壁纸：图库中以暗色缩略图显示，点击下载按钮即可下载到本地并正常使用。默认视频改为云端下载，安装包明显变小。
5. 自动清理旧日志、旧状态记录和临时备份，开机时不再重复校验未改动的视频。
6. 每次连接改用随机本地端口，并在安全说明中补充本地调试连接的注意事项。

已经在使用中的 Codex 窗口不会被自动关闭；下次打开 Codex 时即可自动接上壁纸。暂停壁纸或恢复原始外观后，此功能随之停用。删除已下载的云端壁纸后，它会恢复为可再次下载的云端卡片。
