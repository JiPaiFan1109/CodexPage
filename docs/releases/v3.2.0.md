# CodexPage 3.2.0

本版改善后台恢复、启动连接和异常后的可恢复性，保留现有界面布局与壁纸数据格式。

## 用户可见变化

- 使用 Windows 当前用户任务托管壁纸监控：登录启动、周期检查和异常恢复，避免重复后台。
- 普通入口缺少壁纸连接时提供可延后的重连提示，仍须用户确认才重启 Codex。
- 备份可确认的普通 Codex 快捷方式，卸载时恢复未被用户再次修改的入口；自定义参数入口保留。
- 清晰度保存失败保留本次调整，可重试或明确放弃，不再静默覆盖。
- 单项图库目录权限异常不拖垮整库；损坏图片预览及时释放文件占用。
- 修复失效打包输入和过期回归测试，改善保存失败提示及转换器下载说明。

## 安装与升级

下载 `CodexPage-Setup.exe`，退出 CodexPage 后覆盖安装即可，无需先卸载；壁纸库与设置保留。已运行的 Codex 若缺少连接参数，仍可能需要确认重连。旧客户端的更新地址、安装包别名与签名协议继续兼容。

本版纳入此前本机独立后台保护补丁的能力。官方 Codex 应用列表、更新器及所有任务栏入口不能保证全部接管；无参数的现有会话不会被擅自重启。任务计划不可用时降级为会话内监控，不保证系统托管恢复。

## 验证边界

发布检查包含脚本/Node 回归、签名与文件清单、隔离安装升级卸载及托管 Windows CI。实际完成情况见同目录 v3.2.0-validation.md。未宣称完成真实 GPU/多屏/辅助技术、断电或满盘验收，也没有覆盖维护者生产安装。安装 EXE 尚无项目 Authenticode 签名；更新清单使用既有 RSA 签名。
