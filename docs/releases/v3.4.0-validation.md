## 关闭与进程退出

LibraryLoad、Refresh、EngineLocate、更新检查和下载等待的关闭测试设有 2 秒上限；真实 HTTP 服务不返回响应时，关闭中止 GetResponse，不在 UI 线程等待网络超时。另用独立 PowerShell 进程运行真实 ShowDialog 和 finally，覆盖普通等待、更新等待、Thread.Sleep 模拟不响应 PowerShell 取消的底层调用，断言关闭后 5 秒内进程退出（应用启动耗时另计）。仅专用管理器入口启用退出自身宿主的兜底，嵌入调用不结束调用方进程。

写入壁纸/安装期间不强制中断事务。管理器明确提示可最小化；安装进度窗口的关闭按钮转为最小化，完成或失败后可正常结束/返回。真实物理驱动故障不在这些软件故障注入的保证范围内。
