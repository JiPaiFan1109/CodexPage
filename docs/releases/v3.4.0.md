# CodexPage 3.4.0

- 每天首次打开时自动检查更新，发现新版后居中显示更新说明，可确认更新或跳过此版本；手动检查可再次查看被跳过的版本。
- 更新确认后直接显示进度：左侧当前步骤、右侧 CodexPage 字标，下载显示真实百分比，校验和安装显示阶段状态。
- 下载完成并通过签名、SHA-256 校验后自动安装，无需再次点击。支持取消下载、检查失败和安装交接失败恢复，保留壁纸库与设置。
- 手动检查支持取消；图库读取或检测等待时可关闭，并避免底层只读调用不响应取消时残留管理器进程。安装写入期间关闭会转为最小化，避免破坏安装。
- 修复图库后台加载完成后“上一页 / 下一页”按钮仍被禁用的问题。
- 保留 3.3.1 的无控制台后台、旧计划任务迁移、连接与应用性能优化，以及此前壁纸应用后误回跳修复。

安装包未使用项目 Authenticode 代码签名，更新清单沿用既有 RSA 签名。自动检查按 Windows 本地日期计算；失败沿用网络退避策略。详细验证与限制见 [验收记录](https://github.com/JiPaiFan1109/CodexPage/blob/main/docs/releases/v3.4.0-validation.md)。
